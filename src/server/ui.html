    Identify speakers by voice?

    Vox will keep a voiceprint for each speaker in a database on the vox server so it can label who said what. Voiceprints are never uploaded anywhere else.

    You can rename or forget any speaker at any time. This is an opt-in biometric feature.

    People

    Everyone the vox server keeps a voiceprint for. Memory is off for each person until you switch it on. With it on, what they say in Live Talk while speakers are identified, and what vox answered, is kept on the server and brought back in later conversations.

    The open Live Talk conversation can still contain what they said.

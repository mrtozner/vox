# Vox 0.8.0 adds local LLM runtime choices

Vox can now use a local server that implements the OpenAI chat protocol. Ollama is the default. Choose llama.cpp on macOS, Linux, or Windows, or MLX LM on Apple Silicon. Start the runtime with a local model, then run Vox with:

```bash
VOX_LLM_BACKEND=openai-compatible VOX_LLM_HOST=127.0.0.1:8080 vox serve --offline
```

Set `VOX_LLM_MODEL` to pick a default model ID from your runtime. The selected runtime handles Chat, Live Talk, Converse, and memory summaries. Model discovery uses `GET /v1/llm-models`. `vox chat` and `vox tune` accept the same environment variables. [Runtime setup](https://github.com/mrtozner/vox/blob/v0.8.0/README.md#choose-a-local-llm-runtime)

## Live Talk

- The browser transfers completed microphone buffers directly from the audio worklet to the main thread.
- The new **turn end to audio** measure runs from receipt of the server's turn-end signal to the start of reply playback. It includes transcription.
- Overlapping connections share the same forget state. Playback feedback applies to the correct turn, and open sessions stay available through idle sweeps and capacity eviction.

## Privacy and reliability

- Offline requests connect directly to loopback LLM endpoints with proxies and redirects disabled. The privacy ledger records requests to the configured runtime.
- Forced model refreshes preserve the installed file until its replacement passes verification. Offline refusal leaves existing model files intact.
- Voiceprint collection honors consent withdrawals during enrollment and deferred adaptation writes.

## Downloads

The release includes archives for Linux x86_64 and ARM64, macOS Apple Silicon, and Windows x86_64. Linux requires glibc 2.39 or later. x86_64 requires an x86-64-v3 CPU. macOS requires version 13.4 or later. Whisper's Linux ARM64 build targets ARMv8-A.

Linux and macOS archives bundle Piper's `espeak-ng-data` directory. Keep it beside `vox`. The server can use Kokoro when the Piper phonemizer fails to start. Windows uses Kokoro and requires the Microsoft Visual C++ x64 Redistributable. The distributed binaries are GPL-3.0. See `NOTICE` in each archive. [Platform requirements](https://github.com/mrtozner/vox/blob/v0.8.0/README.md#prebuilt-binary)

Check the archive against `SHA256SUMS` and verify its provenance with `gh attestation verify <archive> --repo mrtozner/vox`.
